# Todo Space

Сучасний мінімалістичний застосунок для керування щоденними завданнями. Допомагає тримати фокус, відстежувати прогрес і зберігати список справ у простому та приємному інтерфейсі.

Проєкт реалізує просунутий рівень практичного завдання: frontend взаємодіє з власним Express API, а дані зберігаються у файловій системі сервера. 
## Можливості

- створення та видалення завдань;
- позначення виконаних завдань;
- фільтрація за статусом;
- очищення всіх виконаних завдань;
- візуальний прогрес виконання;
- адаптивний дизайн для комп'ютерів і мобільних пристроїв;
- плавні анімації та українська локалізація.

## Технології

- HTML5;
- CSS3;
- JavaScript;
- Node.js;
- Express.

## Запуск локально

1. Клонуйте репозиторій:

   ```bash
   git clone https://github.com/xygozhnik/todo-space.git
   cd todo-app
   ```

2. Встановіть залежності:

   ```bash
   npm install
   ```

3. Запустіть сервер:

   ```bash
   npm start
   ```

4. Відкрийте [http://localhost:3000](http://localhost:3000).

## Структура проєкту

```text
todo-app/
├── public/
│   ├── index.html
│   ├── script.js
│   └── style.css
├── server.js
├── tasks.json
└── package.json
```

Завдання зберігаються локально у файлі `tasks.json`.
